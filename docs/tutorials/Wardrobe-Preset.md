# 保存与分享配装

## 你将完成

把基础形象与多个装饰保存成预设，导出备份，并发布到模型库。

## 准备

- 已启用一个基础形象。
- 已添加至少一个装饰实例。
- 已阅读[装扮预设](/omnimorph/presets)。

## 步骤 1：调整配装

1. 打开衣柜 → 配装。
2. 选择基础形象。
3. 加入装饰，调整挂载与变换。
4. 确认预览效果。

## 步骤 2：保存为预设

1. 打开“装扮预设”。
2. 输入名称。
3. 点击“另存新预设”。
4. 确认保存成功。

本地预设保存在此设备；个人云端预设仅本人可读。

## 步骤 3：导出备份

1. 打开“我的形象集”。
2. 选择本地形象/装饰。
3. 点击“导出为 ZIP”。
4. 在 `omnimorph/export/` 查看文件。

## 步骤 4：发布预设

1. 在配装预览操作区点击“发布当前形象”。
2. 选择用途“装扮预设”。
3. 填写名称、描述、分类、标签、封面。
4. 选择公开性与授权要求。
5. 等待依赖检查与上传。

发布不会自动上传源模型；本地依赖需要先映射为云端资源。

## 步骤 5：分享

- 公开模型：其他玩家可在模型库搜索；
- 私有模型：授权后才能使用；
- 分享预设时，提醒对方准备依赖资源。

## 排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 保存失败 | 名称/配置无效 | 检查名称与草稿 |
| 导入后位置错 | 实例 ID 重分配 | 检查锚点与骨骼 |
| 发布失败 | 依赖不可用/限额 | 查看失败项并重试 |
| 对方看不到 | 公开性/授权/展示 | 检查设置 |
