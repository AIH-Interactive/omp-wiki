# 投稿模型

## 你将完成

把一个本地形象或装饰发布到模型库，并设置公开性与授权。

## 准备

- 模型/装饰在本地可正常加载。
- 已准备展示名称、描述、分类、标签。
- 可选：封面 PNG/JPEG。
- 已阅读[投稿、授权与审核](/omnimorph/publish)。

## 步骤 1：打开上传

1. 打开模型库。
2. 点击“上传模型”。
3. 选择用途：形象 / 装饰 / 装扮预设。

## 步骤 2：选择文件

- 形象：`.zip`，根目录含 `avatar.json`；YSM 可用 `.ysm`；
- 装饰：含 `cosmetic.json` 的目录或 ZIP；
- 预设：已保存的预设配置。

## 步骤 3：填写元数据

- 展示名称；
- 描述；
- 分类；
- 标签（可选，逗号分隔）；
- 公开性；
- 是否需要授权；
- 封面（可选）。

注意服务器字节上限与标签数量限制。

## 步骤 4：预览与发布

1. 点击“预览本地草稿”。
2. 确认模型/封面。
3. 点击“发布模型”。
4. 等待上传与服务器校验。

失败时可以“重试同一次上传”，不要重新创建草稿。

## 步骤 5：管理

- 在“我的模型”编辑信息；
- 管理授权名单；
- 设为公开/私有；
- 查看下载/收藏；
- 处理举报/申诉；
- 回收站恢复或彻底删除。

## 排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 无法准备文件 | 格式/清单缺失 | 检查 `avatar.json`/`cosmetic.json` |
| 元数据错误 | 超字节/格式码 | 按提示缩短或清理 |
| 上传失败 | 网络/限额/权限 | 检查后端与限额，重试 |
| 发布后看不到 | 审核/公开性/屏蔽 | 查看状态与后端 |
