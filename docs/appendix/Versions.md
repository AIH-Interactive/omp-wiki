# 版本与兼容性

| 项目 | 值 |

版本或代码更新后，本页应同步更新。

## 兼容性说明

- Figura 形象、脚本与大部分 API 继续可用。
- YSM 模型的支持范围取决于模型格式与当前构建。
- 云端功能取决于后端协议与能力开关。
- 光影、GPU、多人视觉行为仍需真实客户端验收。

## 状态标记

| 标记 | 含义 |
| --- | --- |
| 稳定 | 当前版本可用，行为有源码或验收记录支持 |
| 预览 | 功能存在，但界面或行为可能变化 |
| 依赖后端 | 需要兼容后端与相应能力开关 |
| 2.0 占位 | 界面存在但业务尚未实现 |

## 未验证项

以下内容无法仅靠源码或自动测试证明，文档中统一标注为待验证：

- 真实 Windows 客户端中的界面布局与字体渲染；
- 光影（Iris）下的最终画面；
- GPU 加速路径的实际画面与性能；
- 多人环境下其他玩家看到的模型与动态状态；
- 不同 YSM 模型版本的兼容性。
