# 装扮预设

> 状态：稳定（本地与个人云端预设）；发布能力依赖后端
> 适用版本：OmniMorph 1.0.0-alpha.4.1

装扮预设把“基础形象 + 多个装饰实例 + 锚点/变换”保存成一套可重复使用的配置。预设不是模型本身，它引用模型与装饰资源。

## 三个概念

| 概念 | 说明 |
| --- | --- |
| **草稿** | 当前衣柜中尚未正式应用的搭配 |
| **预设** | 保存下来的搭配，可复用、可发布 |
| **正式装备** | 当前实际启用、其他玩家可能看到的搭配 |

保存预设不会自动上传依赖模型，也不会自动启用。

## 本地预设与个人云端预设

| 类型 | 保存位置 | 可见性 | 依赖 |
| --- | --- | --- | --- |
| 本地预设 | 此设备 | 仅本人 | 引用本地资源；换设备需重新准备 |
| 个人云端预设 | 云端 | 仅本人可读 | 不上传依赖模型；发布时单独检查 |

个人云端预设不会公开，也不会自动把源模型上传为公开资源。

## 保存预设

1. 在衣柜中调整好基础形象与装饰。
2. 打开“装扮预设”。
3. 输入预设名称。
4. 选择：
   - **另存新预设**：创建新预设；
   - **覆盖所选预设**：更新已有预设。
5. 确认保存。

保存失败时，可以使用“重试上一保存”，它使用上一次的原始名称、配置、操作 ID 与预期修订号，不会使用之后改写的输入。

## 预览与导入

- **预览 / 重试**：读取预设及固定版本依赖，准备预览；
- **导入到草稿**：用预设替换当前未应用草稿；
- 导入会为副本分配新的实例 ID，正式装备保持不变；
- 依赖不可用时，会列出失败项；原预设和草稿都会保留。

## 依赖检查

预设可能依赖：

- 本地形象/装饰；
- 云端形象/装饰；
- 固定修订的资源。

发布前必须把本地或外站依赖映射为后端有权使用的云端资源。检查失败时：

1. 查看失败项列表；
2. 确认资源仍存在且有权限；
3. 必要时重新加入衣柜或重新下载；
4. 重试。

## 发布预设

1. 在配装预览操作区点击“发布当前形象”（无选中资源时发布当前形象）。
2. 选择用途“装扮预设”。
3. 填写元数据、封面、公开性与授权。
4. 等待依赖检查与上传。
5. 发布成功后，预设进入“我的形象集”。

发布不会自动上传源模型；依赖需要单独处理。

## 限制

- 预设数量、配置字节、实例数、虚拟锚点、拖尾等受后端 `outfit.limits` 限制；
- 修订冲突时保留原文件，不会静默覆盖；
- 预设中的 UUID 在导入其他草稿时会重新分配；
- 预设不保存“界面选择、树展开、搜索状态”等临时 UI 状态。

## 常见问题

**保存按钮不可用？**
检查预设名称、当前草稿是否有效，以及基础形象来源是否已解析。

**导入后装饰位置变了？**
导入会重新分配实例 ID 并重写内部引用；检查锚点与骨骼是否仍然有效。

**发布时提示依赖不可用？**
先完成依赖映射，或让资源作者重新公开/授权对应资源。
