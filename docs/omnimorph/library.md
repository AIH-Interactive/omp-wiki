# 模型库

> 状态：依赖后端
> 适用版本：OmniMorph 1.0.0-alpha.4.1

模型库用于浏览、搜索、收藏、下载和上传模型。它需要兼容的后端服务；服务器未开启模型库能力时，页面会显示“此服务器尚未支持模型库”。

## 三个范围

| 范围 | 内容 |
| --- | --- |
| **模型库** | 所有公开模型 |
| **我的模型** | 你上传的模型，包括私有与被屏蔽的模型 |
| **我的收藏** | 你收藏的模型 |

## 浏览与筛选

可以使用：

- **搜索**：按名称、作者等过滤；
- **分类**：模型分类；
- **类型**：Figura / YSM / 加密 YSM；
- **授权**：需要授权 / 无需授权；
- **排序**：最新、下载量、收藏量、名称；
- **分页**：上一页 / 下一页，卡片数量随窗口大小调整。

卡片会显示封面、名称、作者、上传者、下载/收藏数、公开性和锁定状态。

## 预览与启用

1. 点击卡片选中模型。
2. 在右侧查看预览与详细信息。
3. 选择操作：
   - **下载并启用**：下载资源并装备到角色；
   - **加入衣柜**：把资源加入“我的形象集”，不自动装备；
   - **收藏 / 取消收藏**；
   - **重试启用**：上一次下载或准备失败时重试。

:::note
“加入衣柜”与“下载并启用”是独立操作。加入衣柜只增加一个可用资源，不会更换你当前的形象或配装。
:::

## 上传模型

模型库支持三种用途：

| 用途 | 源文件 |
| --- | --- |
| 形象 | `.zip`，根目录含 `avatar.json`；YSM 可用 `.ysm` |
| 装饰 | 含 `cosmetic.json` 的目录或 ZIP |
| 装扮预设 | 已保存的预设或 `OutfitConfig` JSON |

上传步骤：

1. 点击“上传模型”。
2. 选择用途。
3. 选择或拖入文件。
4. 填写展示名称、描述、分类、标签。
5. 选择公开性或“需要授权”。
6. 可选：上传自定义封面（PNG / JPEG）。
7. 预览本地草稿。
8. 点击发布。

上传过程会显示读取元数据、准备分发包、检查限额、上传、服务器校验等阶段。失败时可以重试同一份草稿，不需要重新选择文件。

### 元数据限制

- 展示名称、描述、标签受服务器字节上限限制；
- 文本不能包含格式码或不支持的控制字符；
- 标签数量有上限；
- 封面只接受 PNG / JPEG；
- 超出上限会给出具体字段与限制。

### 依赖

- 形象与装饰会按源文件打包；
- 装扮预设的依赖需要单独检查；
- 发布预设不会自动把源模型上传为公开资源；
- 本地或外站依赖需要先映射为后端有权使用的云端资源。

## 公开性与授权

| 设置 | 效果 |
| --- | --- |
| 公开 | 所有玩家可在模型库看到 |
| 私有 | 仅自己可见；授权名单保留但他人无法访问 |
| 需要授权 | 其他玩家需要被授予权限后才能使用 |

- 上传者自动获得授权，且不能撤销自身授权。
- 授权管理支持按玩家名查找、授予、撤销。
- 私有期间授权名单不会丢失；改回公开后继续生效。

## 举报、申诉与回收站

- **举报**：在模型卡片上提交举报原因（最多 512 个 UTF-8 字节）。
- **申诉**：被屏蔽的模型可以在“我的申诉”中申请复核。
- **回收站**：模型库与衣柜各有来源；支持恢复与彻底删除。
- **恢复**：不会覆盖玩家已有的新装备或新上传；来源变化时会提示刷新。
- **屏蔽**：被屏蔽的模型仅本人可见；解除屏蔽后仍保持私有，不自动装备。

## 管理员功能

管理员登录后可以：

- 编辑模型基础信息；
- 管理公开性、授权与屏蔽；
- 处理举报与申诉；
- 查看回收站并恢复/彻底删除；
- 管理当前衣柜模型。

管理员操作需要再次点击确认，避免误操作。

## 状态与错误

| 状态 | 含义 |
| --- | --- |
| 正在加载 | 请求进行中 |
| 暂无符合条件的模型 | 筛选结果为空 |
| 模型库离线 | 无法连接后端 |
| 此服务器尚未支持模型库 | 后端未开启能力 |
| 无法加载模型 | 请求失败，可刷新重试 |
| 需要授权 | 当前账号没有使用权限 |

常见错误码与处理见[常见问题与排错](/omnimorph/troubleshooting)。
