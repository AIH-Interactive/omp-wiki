# 设置项说明

> 状态：稳定
> 适用版本：OmniMorph 1.0.0-alpha.4.1

本页说明 OmniMorph 新增或改名的常用设置。原版 Figura 的界面、动作轮盘、纸娃娃、名称显示等设置继续保留。

## 目录与网络

| 设置 | 说明 |
| --- | --- |
| **OmniMorph 文件夹位置** | 数据根目录；修改后新资源写入新目录 |
| **导出目录** | “导出为 ZIP”的输出位置，默认 `export` |
| **服务器地址** | 后端 origin，例如 `https://example.com`；不要带 `/api` 或凭证 |
| **云端协议** | Protobuf（默认）或 Figura Cloud（兼容） |
| **允许网络访问** | 关闭后脚本/资源相关的网络功能受限 |
| **网络访问限制** | 默认“无限制”；可按需要收紧 |

修改服务器地址或协议会断开并重新认证。

## 缓存

| 设置 | 说明 |
| --- | --- |
| **自动缓存形象集** | 默认关闭；开启后自动缓存当前账号可访问的云端形象，但不自动启用 |

关闭自动缓存不会删除已有缓存；选择、加入或启用资源时仍会按需缓存并校验权限。

## 声音

| 设置 | 说明 |
| --- | --- |
| **Avatar 音量增益** | 统一调整 Figura 与 YSM 模型声音的倍率，0 为静音，1 为原音量，最大 10 |

该增益与游戏玩家音量、模型音量权限叠加，对正在播放的声音生效。

## 硬件加速

| 设置 | 说明 |
| --- | --- |
| **启用硬件加速** | 默认关闭；应用后检测硬件 |
| **加速方式** | 自动 / 仅 SIMD / GPU |
| **当前状态** | 只读显示实际模式与回退原因 |

详见[硬件加速](/omnimorph/hardware-acceleration)。

## 动作轮盘

| 设置 | 说明 |
| --- | --- |
| **动作轮按键** | 打开动作轮盘的按键 |
| **动作轮模式** | 按住 / 切换 / 松开触发等 |
| **动作轮大小** | 轮盘尺寸 |
| **标题位置** | 鼠标、顶部、中间、底部等 |
| **槽位提示文字** | 顶部 / 中央 / 底部 |
| **物品装饰** | 是否显示伤害栏、物品数量等 |

## 界面与名称

| 设置 | 说明 |
| --- | --- |
| **界面语言** | 简体中文 / 英文 |
| **衣柜文件名** | 使用文件名而不是元数据名称显示 |
| **名称显示** | 玩家、实体、Tab 列表、聊天栏的名称自定义等级 |
| **纸娃娃** | 开关、大小、位置、倾斜、偏转 |

## 脚本与调试

| 设置 | 说明 |
| --- | --- |
| **print 输出位置** | 聊天栏 / 日志 |
| **记录非主机脚本** | 允许调试其他玩家脚本 |
| **pings 数据记录** | 关闭 / 聊天栏 / 日志 |
| **同步 pings** | 从后端接收 pings，还是本地运行 |
| **脚本格式** | 关闭 / 轻度 / 重度压缩（需重新选择形象生效） |
| **更新通道** | 无 / 正式版 / 快照 |

## 紧急按钮

“紧急按钮”会停止所有角色渲染，用于临时恢复操作；不会删除模型或配置。
