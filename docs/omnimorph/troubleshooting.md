# 常见问题与排错

> 状态：稳定
> 适用版本：OmniMorph 1.0.0-alpha.4.1

本页按“现象 → 可能原因 → 处理”组织常见问题。排查前建议先备份 `omnimorph` 文件夹。

## 模型不显示

| 检查项 | 处理 |
| --- | --- |
| 文件是否在 `avatars/` | 放入后点击刷新 |
| 是否有 `avatar.json` / `ysm.json` / `main.json` | 补全清单文件 |
| 格式是否受支持 | 查看[模型文件格式](/start_here/Avatar%20File%20Format) |
| 是否被筛掉 | 切换来源/格式筛选与搜索 |
| 是否超限 | 查看模型统计/权限与日志 |
| 脚本是否报错 | 查看 `logs/latest.log` |

## 云端未连接

1. 检查设置中的服务器地址是否为 origin（不要带 `/api`）。
2. 确认协议与后端匹配。
3. 确认网络/代理允许 HTTPS/WSS。
4. 离开并重新进入服务器，或重启游戏。
5. 查看后端状态与日志。

离线模式是否可用取决于后端验证服务器配置；配置正确时离线模式也可以使用云端。本地模型、衣柜和脚本不受影响。请联系服务器管理员确认后端验证规则。

## 上传/下载失败

- 检查服务器限额（文件大小、并发、频率）。
- 检查文件格式与完整性。
- 私有/需授权资源需要相应权限。
- 失败后可以重试同一操作；不要重复创建新操作 ID。
- 缓存失败时，先清理对应缓存再重试。

## 配装/预设不同步

- 后端可能未开启 `outfits_v1` 的配置/预设/应用/事件能力。
- 客户端不会在能力缺失时假装配装已同步。
- 检查预设依赖是否全部可用。
- 修订冲突时保留原文件，不会静默覆盖；重新加载后再编辑。

## 装饰不显示或位置错误

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 完全不显示 | 挂点/骨骼不存在、`supported_bases` 不含当前基础 | 检查 `cosmetic.json` 与骨骼树 |
| 位置偏移 | `default_transform` 或实例变换错误 | 重置变换后重新调整 |
| 只有部分可见 | 编辑范围/覆盖限制 | 检查 `editable_bones` 与预算 |
| 第一人称看不到 | 依赖身体几何 | 挂到手臂/相机相关挂点 |

## 粒子/拖尾不显示

- 检查粒子数量/层数/面数/顶点预算。
- 检查纹理是否属于当前资源。
- Ribbon 需要有效历史；目标失效/换世界会停止绘制。
- 动态光源受每穿戴者上限限制；超限的粒子仍显示但不发光。
- 光影下检查 Iris 兼容性与混合模式。

## 脚本错误

- 错误会显示在名字牌或日志中；悬停查看原因。
- 先检查 `nil`、拼写、API 是否存在。
- 装饰脚本使用受限 API；不要访问其他作者或主机能力。
- 预览环境不写持久化；不要把预览值当作正式保存。

## 游戏崩溃

1. 记录崩溃前的操作与模型。
2. 查看 `logs/latest.log` 与崩溃报告。
3. 移出最近加入的模型/装饰，确认是否复现。
4. 如果与光影/GPU 有关，先关闭光影或硬件加速对比。
5. 提交问题时附上：OmniMorph 版本、Minecraft/Fabric/Java 版本、日志、复现步骤。

## 性能问题

- 关闭硬件加速对比；
- 降低粒子/拖尾/光源数量；
- 检查模型复杂度与纹理尺寸；
- 光影下自定义粒子成本更高；
- 记录 FPS 与场景，便于定位。

## 安全模式

设置中的“紧急按钮”可以停止所有角色渲染，用于临时恢复操作。它不会删除模型或配置。

## 日志位置

```text
.minecraft/logs/latest.log
.minecraft/crash-reports/
```

提交问题时请同时说明是否安装光影、LambDynamicLights、其他渲染模组。
