# OmniMorph 功能

本节介绍 OmniMorph 在 Figura 基础上新增的界面与能力，按“衣柜与配装 → 模型库与云端 → YSM 与 Molang → 渲染与设置”的顺序组织。

## 衣柜与配装

- [衣柜与形象集](/omnimorph/wardrobe)：三栏布局、来源筛选、缓存、展示与发布。
- [装饰系统](/omnimorph/cosmetics)：`cosmetic.json`、多实例、骨骼树、内部覆盖。
- [骨骼挂载与虚拟锚点](/omnimorph/anchors)：标准挂点、骨骼、虚拟锚点与循环依赖。
- [装扮预设](/omnimorph/presets)：草稿、本地/个人云端预设、依赖与发布。
- [装饰动画](/omnimorph/cosmetic-animations)：衣柜中的动作预览（仅草稿）。
- [模型专用设置](/omnimorph/avatar-controls)：控件类型、页面、键位、持久化。
- [导出为 ZIP](/omnimorph/export)：备份与分享本地资源。

## 模型库与云端

- [模型库](/omnimorph/library)：浏览、搜索、收藏、下载与启用。
- [投稿、授权与审核](/omnimorph/publish)：上传、公开性、授权、举报、申诉、回收站。
- [云端同步](/omnimorph/sync)：协议、能力、限额、资源分发与排错。

## YSM 与 Molang

- [YSM 模型支持](/omnimorph/ysm)：格式、加载、纹理、动画、子实体、兼容性。
- [Molang 表达式与控制器](/omnimorph/molang)：查询、变量、控制器、与 Lua 联动。
- [YSM 动作轮盘](/omnimorph/action-wheel)：页面、槽位、动作、键位绑定。

## 渲染与设置

- [第一人称、光影与动态光源](/omnimorph/rendering)：相机相对姿态、Iris、LambDynamicLights。
- [硬件加速](/omnimorph/hardware-acceleration)：自动 / 仅 SIMD / GPU 与回退。
- [设置项说明](/omnimorph/settings)：目录、网络、缓存、音量、界面。
- [常见问题与排错](/omnimorph/troubleshooting)：模型、云端、装饰、粒子、崩溃。
- [从 Figura 迁移](/omnimorph/migration)：迁移步骤、兼容性与回滚。

## 当前状态

全站正文已完成中文化。部分 API 页面仍在补充更易懂的说明；未完成处会在标题下标注状态。

- 稳定：当前版本可用。
- 预览：功能存在，但界面或行为可能变化。
- 依赖后端：需要兼容后端与相应能力开关。
- 2.0 占位：界面存在但业务尚未实现。
