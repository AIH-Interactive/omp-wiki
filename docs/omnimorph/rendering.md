# 第一人称、光影与动态光源

> 状态：稳定（基础行为）；真实光影/GPU 画面仍需实机验证
> 适用版本：OmniMorph 1.0.0-alpha.4.1

本页说明 OmniMorph 在第一人称、Iris 光影和动态光源下的渲染行为，以及常见问题的排查方向。

## 第一人称

第一人称下，配装组合会：

- 按相机相对全身姿态每帧重放一次；
- 丢弃重复的配装几何，避免第一人称看到穿模；
- 身体挂点装饰的 `RENDER` / `POST_RENDER`、粒子与拖尾继续运行；
- 基础与手臂的 part-to-world 矩阵按当前帧更新。

这意味着：

- 第一人称可以看到粒子、拖尾与部分装饰效果；
- 但不应期待完整身体几何在第一人称中重复绘制；
- 如果装饰“只在第三人称出现”，先确认它是否依赖身体几何。

## Iris / 光影

安装 Iris 后：

- 自定义粒子管线按混合模式映射到 Iris 的粒子程序；
- 阴影阶段跳过自定义粒子的回调/提取、粒子组提交，以及配装脚本的 `POST_RENDER` 发射；
- 阴影视图会剔除相机平移，避免拖尾/粒子偏离原位。

:::note
光影下的最终画面受光影包、Iris 版本与 GPU 影响；自动测试不能替代真实窗口验收。
:::

## LambDynamicLights

安装 LambDynamicLights 时：

- 粒子动态光源通过其公开 `DynamicLightBehavior` API 注册为世界光源；
- 内置光场停止注入，避免双重照明；
- 世界切换后自动重新注册；
- 未安装时输出一次回退警告，并继续使用内置光场。

## 动态光源上限

- 每个穿戴者的光源数量受后端 `outfit.limits` 限制；
- 超过上限时，只保留先前启用的前 N 个；
- 其余粒子仍然存在并正常显示，但不发光；
- `setLightInterval(n)` 可以让每隔 n 个可发光粒子只让一个成为光源，其余粒子仍显示。

## 纸娃娃与世界预览

- 关闭衣柜后不保留草稿世界预览；
- 世界身体绘制固定使用 `RENDER`；
- part-to-world 矩阵每帧刷新；
- 纸娃娃预览不会泄漏渲染模式。

## 常见问题

**开光影后粒子/拖尾偏移？**
确认使用的是当前版本；旧版本存在阴影视图未剔除相机平移的问题。仍异常时尝试关闭光影对比。

**第一人称看不到装饰？**
装饰可能依赖身体几何，第一人称会丢弃重复几何；检查是否应挂到手臂或相机相关挂点。

**动态光源不亮？**
检查 LambDynamicLights 是否安装、光源上限是否已满、`setDynamicLight` 是否开启，以及光影包是否支持动态光源。

**双重照明？**
确认只使用一种光源路径；安装 LambDynamicLights 后内置光场会停止注入。
