# 导出为 ZIP

> 状态：稳定
> 适用版本：OmniMorph 1.0.0-alpha.4.1

“导出为 ZIP”把本地形象或装饰打包，便于备份、分享或迁移到其他设备。

## 前置条件

- 资源是本地资源（不是仅云端缓存）；
- 资源目录存在且可读；
- 有可写的导出目录。

## 操作步骤

1. 打开“我的形象集”。
2. 选择本地形象或装饰。
3. 点击“导出为 ZIP”。
4. 等待后台导出。
5. 在导出目录查看结果。

默认导出目录：

```text
omnimorph/export/
```

可以在设置 → 导出目录中修改。

## 文件命名

| 类型 | 文件名 |
| --- | --- |
| 形象 | `avatar_名称.zip` |
| 装饰 | `cosmetic_名称.zip` |
| 加密 YSM | 保留 `.ysm` 扩展名 |

- 重名时追加 `(2)`、`(3)`；
- 保留源目录结构；
- 导出在后台执行，完成后显示结果。

## 失败排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 导出按钮不可用 | 不是本地源，或源不存在 | 选择本地资源 |
| 导出失败 | 目录不可写/磁盘满 | 检查导出目录与空间 |
| 找不到文件 | 导出目录被修改 | 查看设置中的导出目录 |

## 注意

- 导出的是源文件，不包含云端缓存或账号信息；
- 加密 `.ysm` 以原文件形式导出；
- 导出不会修改原资源；
- 分享前确认模型/装饰的许可与作者署名。
