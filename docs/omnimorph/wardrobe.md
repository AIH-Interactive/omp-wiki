# 衣柜与形象集

> 状态：稳定（配装/形象集）；整套云端应用取决于后端能力
> 适用版本：OmniMorph 1.0.0-alpha.4.1

本页深入说明衣柜的三栏布局、形象集、配装候选、缓存与发布。第一次使用请先看[衣柜总览](/start_here/Wardrobe)。

## 布局

衣柜通常分为三栏：

| 区域 | 内容 |
| --- | --- |
| 左栏 | 形象/装饰/配装/形象集列表，来源与格式筛选 |
| 中栏 | 预览、启用、展示与操作按钮 |
| 右栏 | 模型信息、骨骼树、公告或预设详情 |

窗口过小时界面会提示增大窗口或降低 GUI 缩放。

## 标签与来源

- **形象**：选择基础模型；
- **装饰**：创建/管理装饰；
- **配装**：组合基础与多个装饰；
- **我的形象集**：本地/云端资源管理。

来源：

- **本地**：直接读取本机文件；
- **云端**：从后端获取，受权限与缓存控制；
- **全部**：合并显示。

## 我的形象集

形象集分本地与云端：

- 本地卡片读取本机目录；
- 云端卡片读取后端资源与缓存；
- 选中后右侧预览；
- 支持搜索、格式筛选、滚动与分页；
- “加入配装”只加入候选，不自动启用；
- “缓存所选形象”手动缓存；
- “从形象集移除”只移除成员关系，不删除原模型、当前装备或缓存。

自己成功投稿的资源会进入“我的形象集 → 云端”。

## 配装

- 配装栏使用紧凑条目；
- 左上角图标显示来源（本地/云端）与类型（Figura/YSM）；
- 点击候选只预览，不更换玩家实时预览；
- 点击“启用”才更换化身；
- 支持右键菜单：移出配装、删除自己上传的原模型等；
- 常用操作置前，新建/文件夹按钮只在形象集显示。

## 预览与展示

| 操作 | 作用 |
| --- | --- |
| 预览 | 本地界面查看，不影响角色 |
| 启用 | 更换当前装备 |
| 展示 | 控制当前装备是否对其他玩家可见 |

展示设置只作用于当前已启用的来源与装备版本，不读取预览选择或形象集成员关系。公开与私有模型都可以设置展示，但被屏蔽的模型不能对外展示。

## 缓存

| 状态 | 含义 |
| --- | --- |
| 已缓存 | 本机有完整资源 |
| 未缓存 | 需要下载 |
| 下载中 | 正在获取 |
| 缓存失败 | 下载/校验失败，可重试 |

- 自动缓存默认关闭；
- 关闭不会删除已有缓存；
- 选择、加入或启用时按需缓存并校验权限；
- 预览缓存不能替代正式缓存；
- 权限变化后，已缓存资源仍会重新校验。

## 发布当前形象

- 选中资源时发布所选形象；
- 无选择时发布当前形象；
- 发布前检查依赖、元数据、封面与授权；
- 发布不会自动上传源模型依赖。

## 骨骼树

右栏可以切换到骨骼树：

- 只读；
- 默认折叠；
- 支持搜索与横向滚动；
- 选中部件显示选择框；
- 需要读取脚本后的结构变化时显式刷新。

## 2.0 占位

界面中标注“敬请期待（2.0 实装）”的区域不应当作可用功能；它们可能显示布局但没有完整业务。

## 常见问题

**配装候选点击后没反应？**
确认资源已缓存、权限有效，且基础形象来源已解析。

**启用后其他玩家看不到？**
检查展示开关、公开性、授权与后端连接。

**缓存一直失败？**
检查网络、服务器限额、磁盘空间与资源是否被删除/屏蔽。

**删除按钮删了什么？**
删除云端装备会移除后端保存的当前装备；不会删除本地模型。删除自己上传的原模型会走模型删除流程。
