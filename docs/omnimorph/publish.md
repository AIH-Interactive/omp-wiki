# 投稿、授权与审核

> 状态：依赖后端
> 适用版本：OmniMorph 1.0.0-alpha.4.1

本页说明如何把形象、装饰或装扮预设发布到模型库，以及授权、举报、申诉与回收站的处理方式。

## 投稿前准备

| 用途 | 源文件要求 |
| --- | --- |
| 形象 | `.zip`，根目录含 `avatar.json`；YSM 可用 `.ysm` |
| 装饰 | 含 `cosmetic.json` 的目录或 ZIP |
| 装扮预设 | 已保存的预设或 `OutfitConfig` JSON |

同时准备：

- 展示名称、描述、分类、标签；
- 可选封面（PNG / JPEG）；
- 公开性或“需要授权”；
- 依赖资源的映射（如果使用本地/外站资源）。

## 发布流程

1. 打开模型库 → 上传模型。
2. 选择用途。
3. 选择或拖入文件。
4. 填写元数据。
5. 选择公开性与授权要求。
6. 预览本地草稿。
7. 点击发布。
8. 等待“读取元数据 → 准备分发包 → 检查限额 → 上传 → 服务器校验”。
9. 查看结果与状态。

失败时可以重试同一操作；取消后草稿保留，可以继续编辑。

## 授权

- 上传者自动获得授权，且不能撤销自身授权；
- 其他玩家需要被授予权限后才能使用“需要授权”的模型；
- 授权名单在私有期间保留；改回公开后继续生效；
- 被屏蔽的模型不能被授权或展示。

### 管理授权

1. 打开模型的“授权管理”。
2. 按玩家名查找。
3. 授予或撤销。
4. 确认操作。

## 公开性与展示

| 设置 | 作用 |
| --- | --- |
| 条目公开性 | 是否在模型库中公开 |
| 当前装备展示 | 是否让其他玩家看到你当前的形象 |

两者独立：公开模型可以设置不展示，私有模型也可以在自己可见的范围内设置展示（受后端策略限制）。

## 举报

1. 在模型卡片上点击“举报”。
2. 填写原因（最多 512 个 UTF-8 字节）。
3. 提交。

举报不会自动屏蔽模型；管理员会处理。

## 申诉

1. 打开“我的申诉”。
2. 选择被屏蔽的模型。
3. 提交申诉。
4. 管理员处理后可解除对应来源的屏蔽。

解除一次屏蔽不会影响其他有效屏蔽；模型仍保持私有，不会自动装备。

## 回收站

- 模型库与衣柜各有回收站来源；
- 支持恢复与彻底删除；
- 恢复不会覆盖玩家已有的新装备或新上传；
- 来源变化时会提示刷新。

## 管理员

管理员登录后可以：

- 编辑模型信息；
- 管理公开性、授权、屏蔽；
- 处理举报与申诉；
- 查看回收站；
- 管理当前衣柜模型。

敏感操作需要二次确认。

## 审核与限制

- 服务器可设置上传大小、频率、并发与元数据字节上限；
- 依赖必须可被后端访问；
- 被屏蔽/删除的资源不能继续分发；
- 加密 YSM 不会被服务端解密或执行。

## 常见问题

**发布后模型库看不到？**
检查公开性、审核状态、屏蔽状态与后端能力。

**授权了玩家但对方仍不能用？**
确认对方账号、模型修订、是否被屏蔽，以及对方是否重新加载。

**恢复后装备没回来？**
恢复只恢复资源，不覆盖当前装备；需要手动重新启用。
