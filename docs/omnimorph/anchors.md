# 骨骼挂载与虚拟锚点

> 状态：稳定（标准挂点/骨骼/虚拟锚点）；2.0 组合槽位为占位
> 适用版本：OmniMorph 1.0.0-alpha.4.1

装饰需要挂到基础模型的某个位置。OmniMorph 支持标准挂点、基础骨骼、装饰骨骼和虚拟锚点；当现有骨骼不够用时，可以创建虚拟锚点。

## 挂载类型

| 类型 | 来源 | 适用 |
| --- | --- | --- |
| 标准挂点 | 基础模型预定义 | 头、背、腰、腿、脚、翅膀等 |
| 基础骨骼 | 基础模型的骨骼 | 精确挂到某个骨骼 |
| 装饰骨骼 | 另一个装饰的导出骨骼 | 装饰之间嵌套 |
| 虚拟锚点 | 用户创建 | 自定义位置、额外挂点 |
| 自动拖尾 | 运行时历史 | Trail 类装饰 |

标准挂点名：

```text
head_anchor, face_anchor, hair_anchor, back_anchor, wing_anchor,
hip, tailtip, left_leg_anchor, right_leg_anchor,
left_foot_anchor, right_foot_anchor
```

## 骨骼树

- 只读展示基础与装饰的骨骼层级；
- 默认折叠，支持搜索与横向滚动；
- 选中部件显示选择框，其余半透明；
- 需要读取脚本后的结构变化时，点击“刷新骨骼树”；
- 树不会修改模型本身。

## 创建虚拟锚点

1. 在骨骼树中选择一个父骨骼或实例。
2. 点击“在此创建虚拟锚点”。
3. 输入名称。
4. 选择父级（基础骨骼或装饰实例）。
5. 调整位置与旋转；缩放固定为 1。
6. 点击“确定”返回骨骼树。

:::note
虚拟锚点不能嵌套虚拟节点；父级必须是基础骨骼或装饰骨骼。
:::

## 编辑与删除

- **编辑**：改名、改父级、改变换；预览中的坐标轴标记会实时更新。
- **删除**：需要确认；界面会列出失去绑定的实例。
- 删除父级会影响依赖它的实例；请先调整或删除依赖。

## 挂载装饰

1. 选择装饰实例。
2. 点击“从骨骼树选择挂载目标”。
3. 选择目标（挂点/骨骼/虚拟锚点）。
4. 调整实例变换。
5. 确认。

如果目标不可用、无权使用或会形成循环依赖，绑定会被拒绝。

## 坐标与变换

- 位置单位为模型单位（16/方块）；
- 旋转单位为度；
- 缩放必须为正；
- 组合顺序为：实体外层 × 目标姿态 × 锚点偏移 × 实例偏移 × 装饰姿态；
- 内部骨骼覆盖在作者姿态之后应用。

## 限制

| 项目 | 默认上限 |
| --- | ---: |
| 虚拟锚点 | 128 |
| 层级深度 | 64 |
| 实例 | 32 |
| 内部覆盖 | 1024 |

具体上限由后端 `outfit.limits` 收紧。

## 常见问题

**找不到想要的骨骼？**
先刷新骨骼树；如果模型没有该骨骼，创建一个虚拟锚点并挂到最近的父骨骼。

**挂载后装饰飞了？**
检查父级坐标空间、实例变换与 `default_transform`；重置后再调。

**提示循环依赖？**
装饰 A 挂到 B，B 又挂到 A 会形成环；改成单向依赖。
