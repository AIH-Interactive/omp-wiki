# 云端同步

> 状态：依赖后端
> 适用版本：OmniMorph 1.0.0-alpha.4.1

OmniMorph 通过兼容后端在多人游戏中分发模型资源与动态状态。没有后端时，本地模型仍可正常加载，但其他玩家不会看到你的云端模型。

## 需要后端的功能

| 功能 | 是否需要后端 |
| --- | --- |
| 本地形象/装饰加载 | 否 |
| 衣柜上传、展示 | 是 |
| 模型库浏览、下载、投稿 | 是 |
| 形象集/装扮预设的云端同步 | 是 |
| 配装整套应用与事件 | 是，且需要对应能力 |
| YSM 动态状态同步 | 是 |

## 协议

在设置中选择服务器支持的协议：

| 协议 | 说明 |
| --- | --- |
| **Protobuf** | 默认；需要支持 OmniMorph Protobuf 的后端 |
| **Figura Cloud** | 兼容原有 Figura Cloud 服务 |

客户端不会在协议不兼容时自动切换。切换协议会断开并重新认证。

## 后端部署

OmniMorph 需要兼容的后端服务。推荐使用配套后端：

- [sculptor-for-omni-morph](https://github.com/AIH-Interactive/sculptor-for-omni-morph)
- [后端部署文档](https://github.com/AIH-Interactive/sculptor-for-omni-morph/blob/master/docs/DEPLOYMENT.md)

协议规范见 `omp-ref/protocol/README.md`。

## 服务器地址

- 填写服务器 origin，例如 `https://example.com` 或 `wss://example.com`；
- 可以包含端口；
- 不要包含 `/api`、`/ws`、凭证、查询参数或片段；
- 默认使用 HTTPS/WSS；显式 HTTP/WS 仅在调试模式下允许。

## 能力与限额

后端通过能力声明决定哪些功能可用。例如：

- 衣柜配置；
- 装扮预设；
- 整套应用；
- 事件/观察者。

服务器还可以下发布局限额，例如：

- 每秒消息数与字节数；
- 订阅数与队列；
- 上传并发；
- 快照 TTL；
- 事件尾部数量。

服务器只能收紧限额，不能超过客户端硬上限。

:::warning
如果后端没有开启“整套应用/事件”能力，客户端不会假装配装已同步。此时请使用单形象/单资源模式。
:::

## 资源分发

- 上传后，资源由后端保存并分发；
- 其他玩家按权限、公开性与展示设置决定是否可见；
- 私有模型只有本人与获授权玩家可见；
- 被屏蔽的模型不能对外展示；
- 下载缓存会校验来源、格式与权限。

## 动态状态同步

YSM 模型可以同步动态状态（例如动作、纹理、会话）。同步遵循：

- 发布者会话/代际；
- 快照 + 增量；
- 序列号与过期恢复；
- 慢消费者重新快照或收到明确的丢失错误。

服务端不会执行模型或脚本，也不会解密 YSM。

## 断线与重连

- 连接失败不影响本地模型加载；
- 后端异常断连后会自动重连；
- 重连后重新认证并获取能力；
- 旧请求可能因会话过期而失败，需要重试或刷新。

## 离线模式与账号

- 云端使用玩家 UUID 识别身份；
- 离线模式服务器可能改写 UUID，导致无法匹配云端资源；
- 破解/非正版账号通常无法使用云端；
- 这是账号与服务器行为，不是客户端可以绕过的限制。

## 排错

| 现象 | 检查 |
| --- | --- |
| 一直未连接 | 服务器地址、端口、协议、网络 |
| 连上但看不到模型库 | 后端是否开启模型库能力 |
| 上传失败 | 限额、权限、文件格式、后端日志 |
| 其他玩家看不到 | 展示设置、公开性、授权、屏蔽 |
| 配装不同步 | 后端是否开启整套应用/事件能力 |
| 频繁断线 | 网络稳定性、服务器限额、代理 |

更多见[常见问题与排错](/omnimorph/troubleshooting)。
