这些是“超级秘密设置”（Super Secret Settings）中的屏幕效果。可通过 <code>renderer:setPostEffect(string)</code> 将其应用到形象使用者的第一人称视角（POV）。
更多信息请参阅 [Wiki](https://minecraft.wiki/w/Shaders/Before_1.9)。

**示例**：

```lua
renderer:setPostEffect("creeper")
```

---

## 全部后处理效果

| 效果            | 说明                                                                                                                                                                                                                                                                              |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| creeper         | 旁观苦力怕时的效果。                                                                                                                                                                                                                                                              |
| spider          | 旁观蜘蛛时的效果。                                                                                                                                                                                                                                                                |
| notch           | 使用分辨率减半的 8 位色彩，并带有抖动效果。Notch 的许多其他游戏也使用类似叠加层，此效果正源于此。                                                                                                                                                                                |
| fxaa            | 此着色器会加入少量抗锯齿（平滑锯齿边缘），在地平线附近的树木上最明显。                                                                                                                                                                                                            |
| art             | 像素向外模糊，使移动的物体闪烁。                                                                                                                                                                                                                                                  |
| bumpy           | 勾勒颜色差异，让纹理呈现立体感。（以原始分辨率查看截图时更明显。）                                                                                                                                                                                                                |
| blobs2          | 与 Art 类似，但图形开销更低。                                                                                                                                                                                                                                                      |
| pencil          | 让世界呈现铅笔素描的外观。                                                                                                                                                                                                                                                        |
| color_convolve  | 增强并加入更多颜色，使画面更鲜艳。                                                                                                                                                                                                                                                |
| deconverge      | 将红、绿、蓝三个颜色通道错开。                                                                                                                                                                                                                                                    |
| flip            | 垂直翻转玩家的视角。                                                                                                                                                                                                                                                              |
| invert          | 旁观末影人时的效果。                                                                                                                                                                                                                                                              |
| ntsc            | 让玩家视角呈现 CRT 显示器或电视屏幕的观感。                                                                                                                                                                                                                                       |
| outline         | 与 Bumpy 类似，勾勒颜色差异，但实现更简单。在某些电脑上不会产生效果。                                                                                                                                                                                                             |
| phosphor        | 屏幕上的像素会短暂残留，移动时被“拖出”，随后逐渐淡去。                                                                                                                                                                                                                            |
| scan_pincushion | 与 NTSC 类似，但没有模糊，且图形开销低得多。                                                                                                                                                                                                                                      |
| sobel           | 除纹理边缘外，将视角变为黑色。                                                                                                                                                                                                                                                    |
| bits            | 降低分辨率，并使用 8 位配色。                                                                                                                                                                                                                                                      |
| desaturate      | 大幅降低颜色强度，产生与名称相符的低饱和度效果。                                                                                                                                                                                                                                  |
| green           | 在 Scan Pincushion 与 Bits 的基础上叠加绿色滤镜。                                                                                                                                                                                                                                 |
| blur            | 整体模糊屏幕，与显示的内容无关。                                                                                                                                                                                                                                                  |
| wobble          | 颜色在色相范围内不断循环。所有显示的像素都会按正弦计算上下移动。需要注意的是，该效果只作用于屏幕平面，不会移动屏幕上显示的顶点；观察屏幕边缘就能看到像素在移动。                                                                                                                    |
| blobs           | 与 Blobs2 和 Art 类似，但光斑在近处很小，在远处很大。                                                                                                                                                                                                                             |
| antialias       | 模糊像素边缘以减少锯齿。它比 FXAA 更模糊，但消除纹理和方块锯齿的效果更好。                                                                                                                                                                                                        |
