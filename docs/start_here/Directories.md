# 目录、配置与迁移

> 状态：稳定
> 适用版本：OmniMorph 1.0.0-alpha.4.1

本页说明 OmniMorph 的数据目录、配置文件和从 Figura 迁移时的行为。

## 默认目录

默认数据根目录为：

```text
.minecraft/omnimorph/
```

| 路径 | 用途 | 是否可手动修改 |
| --- | --- | --- |
| `avatars/` | Figura 形象、YSM 模型 | 可以放入或删除模型 |
| `cosmetics/` | 装饰资源 | 可以放入或删除装饰 |
| `export/` | “导出为 ZIP”的输出目录 | 可以在设置中修改 |
| `cache/` | 下载、预览、完整形象缓存 | 不建议手动编辑 |
| `omni-morph.json` | 客户端配置 | 建议通过界面修改 |

:::warning
`cache/` 中的文件是压缩、加密或带校验的内部格式，不是作者源文件。不要手动解包、改名或删除正在使用的缓存；需要清理时优先使用界面提供的缓存操作。
:::

## 模型目录

- 一个 Figura 形象是“包含 `avatar.json` 的文件夹或 ZIP”。
- 一个 YSM 模型可以是受支持格式的文件夹、ZIP 或加密 `.ysm`。
- 一个装饰是“包含 `cosmetic.json` 的文件夹或 ZIP”。
- 模型可以放在 `avatars/` 的子目录中；衣柜会按文件夹展示。
- 以 `.` 开头的文件会被忽略，不会加载。

## 配置

配置保存在 `omni-morph.json`。常用项包括：

- OmniMorph 文件夹位置；
- 服务器地址与云端协议；
- 界面语言；
- 硬件加速；
- 动作轮盘；
- 导出目录；
- 自动缓存形象集；
- Avatar 音量增益。

设置项含义见[设置项说明](/omnimorph/settings)。

## 从 Figura 迁移

首次启动时：

1. OmniMorph 会尝试读取原有 `figura.json`。
2. 旧配置文件会被保留，不会被删除或覆盖。
3. 默认模型目录统一为 `omnimorph`；旧目录仍按兼容逻辑读取。
4. 旧版 Figura 形象、脚本和权限设置继续可用。

:::note
迁移只处理配置与目录，不会把旧版云端资源自动转成 OmniMorph 模型库条目。需要分享模型时，请使用“上传”或“发布”流程。
:::

## 修改数据目录

可以在设置中修改 OmniMorph 文件夹位置。修改后：

- 新目录用于后续模型、装饰、导出与缓存；
- 旧目录不会自动搬移；
- 如果新目录不可写，相关功能会失败并提示。

## 备份建议

在以下操作前，建议备份整个 `omnimorph` 文件夹：

- 更新模组版本；
- 批量删除模型或装饰；
- 修改数据目录；
- 清理缓存。
