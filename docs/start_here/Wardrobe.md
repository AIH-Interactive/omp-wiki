# 衣柜总览

> 状态：稳定
> 适用版本：OmniMorph 1.0.0-alpha.4.1

衣柜是 OmniMorph 的主界面，用来选择、预览、启用和管理形象、装饰与配装。

## 打开衣柜

进入世界后，通过以下方式打开：

- 暂停菜单中的 OmniMorph 按钮；
- 设置中配置的衣柜按键；
- 游戏内命令（如果服务器允许）。

## 四个入口

| 入口 | 用途 |
| --- | --- |
| **形象** | 选择、预览、启用 Figura 形象或 YSM 模型 |
| **装饰** | 创建、管理和挂载装饰 |
| **配装** | 把基础形象与多个装饰组合成一套搭配 |
| **我的形象集** | 管理本地与云端的形象/装饰资源，加入配装或发布 |

## 来源与筛选

衣柜顶部可以切换：

- **来源**：全部 / 本地 / 云端；
- **格式**：全部 / OmniMorph（Figura）/ 非加密 YSM / 加密 YSM；
- **搜索**：按名称过滤；
- **文件夹**：进入子目录；
- **排序**：按名称或时间等。

筛选条件可以组合使用，文件夹内部同样生效。

## 预览、启用与展示

这三个操作容易混淆：

| 操作 | 作用 | 是否影响其他玩家 |
| --- | --- | --- |
| **预览** | 只在本地界面查看模型效果 | 否 |
| **启用** | 把模型装备到你的角色上 | 是（取决于展示设置） |
| **展示** | 控制当前已启用模型是否对其他玩家可见 | 是 |

- 选择条目不等于启用；需要在预览区点击“启用”。
- 公开模型与私有模型都可以单独设置是否向其他玩家展示。
- 被屏蔽的模型不能对外展示。

## 缓存状态

云端资源可能显示：

- **已缓存**：本机已有完整资源；
- **未缓存**：需要下载；
- **下载中**：正在获取；
- **缓存失败**：下载或校验失败，可重试。

自动缓存默认关闭。关闭自动缓存不会删除已有缓存；在选择、加入或启用资源时仍会按需缓存并校验权限。

## 上传、刷新与删除

- **上传当前形象**：把当前形象上传到云端并装备；其他玩家将看到上传版本。
- **刷新当前形象**：重新从云端加载当前上传的形象。
- **删除云端装备**：删除云端保存的当前装备。
- **取消当前装备**：取消本地的当前装备状态。

:::warning
上传后，模型会与本地文件分离。之后修改本地文件不会自动更新云端版本；需要重新上传或使用模型库发布流程。
:::

## 2.0 占位

界面中标注“敬请期待（2.0 实装）”的区域（例如部分装饰组合槽位）尚未实现完整业务，不应视为可用功能。

## 常见问题

**模型在列表中但不显示？**
先确认模型格式受支持，再查看模型统计/权限是否超限，最后检查日志中的脚本或资源错误。

**云端一直显示未连接？**
检查服务器地址、协议与网络；离线模式或破解账号可能无法使用云端。

**点了预览但角色没变？**
预览只影响界面，不会更换角色；需要点击“启用”。
